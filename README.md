## What it does

`main.py` writes one line of plain text to `/output/entry.txt`: the GPS's
own excuse, in its own voice, for sending the driver down the wrong road.
No setup, no dialogue tag — just the excuse itself, short enough to read
aloud in one breath.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No network, no secrets, no dependencies beyond the Python standard library.
